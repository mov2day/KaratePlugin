2.1.0November 5
2026
01

Karate language mode

Syntax highlighting for steps, match operators, fuzzy markers, embedded expressions, tags, example tables and embedded JSON, XML and JavaScript, plus folding for features, scenarios and doc-strings. It only turns on when the official Karate extension is absent and the file looks like Karate.

02

Smart suggestions, no AI model

A local engine predicts the next step from workflow rules and from patterns in your file, and completes keywords, your variables, object keys and response fields it learned from your match lines. No network, no telemetry.

03

Step debugger

Set breakpoints on Gherkin steps, then continue, step over, step in and step out. Inspect variables, evaluate expressions, or pause a running feature before its next step. Run Karate: Debug Feature or use a karate-dsl launch configuration.

04

Karate 2 runs report results again

Runs no longer end with "Karate did not produce a report". Results now come from Karate 2's Cucumber JSON for the standalone CLI, Gradle and Maven, so Run and Test Explorer show real pass and fail counts.

05

Still Workbench, still generating

Step-by-step Workbench with click-to-assert, the shared OpenAPI, Postman, HAR, Jira, Confluence and Scout pipeline, the V2-* quality gate and edit-safe regeneration are unchanged. Workbench needs Karate 2.1+ and Java 21+.
